# RamRuchiAdda Website

ఇది ఆన్‌లైన్ ఫుడ్ ఆర్డరింగ్ వెబ్‌సైట్‌కు ప్రారంభ నమూనా (starter project).

## మీ కంప్యూటర్‌లో నడపడం
1. Node.js LTS ఇన్‌స్టాల్ చేయండి.
2. ఈ ఫోల్డర్‌లో Terminal తెరవండి.
3. `npm install` అమలు చేయండి.
4. `npm start` అమలు చేయండి.
5. బ్రౌజర్‌లో `http://localhost:3000` తెరవండి.

## GitHub Upload
ZIP ను Extract చేసి, అందులోని ఫైళ్లను Repository లో Upload చేయండి. ZIP ఫైల్‌ను నేరుగా Upload చేయవద్దు.

## Render Deploy
- New → Web Service
- GitHub Repository ఎంచుకోండి
- Build Command: `npm install`
- Start Command: `npm start`

## తప్పనిసరిగా పూర్తి చేయాల్సిన పనులు
- నమూనా ఉత్పత్తుల పేర్లు, ధరలు, ఫోటోలు మీ అసలు వివరాలతో మార్చాలి.
- డెలివరీ ప్రాంతాలు, ఛార్జీలు, సమయాలు నిర్ధారించాలి.
- ఇది ప్రస్తుతం డెమో ఆర్డర్ ఫారమ్ మాత్రమే; నిజమైన UPI/Razorpay payment ఇంకా జోడించలేదు.
- Production కోసం సురక్షిత Admin Login, Database, payment verification, order management, privacy/terms pages, backups, security testing అవసరం.
- ఆహార వ్యాపారానికి వర్తించే FSSAI మరియు స్థానిక నిబంధనలు పరిశీలించాలి.
- Render free instance నిద్రపోవచ్చు; production ఆర్డర్లకు సరైన hosting మరియు persistent database ఎంచుకోవాలి.
